Locked param validation pattern (from research):
```python
async def validate_locked_params(run: Run, assignment: Assignment) -> list[str]:
    errors = []
    for param, required_value in (assignment.locked_params or {}).items():
        actual = (run.config or {}).get(param)
        if str(actual) != str(required_value):
            errors.append(f"{param} must be {required_value} — your run used {actual}")
    return errors
```
