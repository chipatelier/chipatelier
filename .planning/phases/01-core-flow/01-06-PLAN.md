    **backend/app/api/routes/vnc.py** — VNC session endpoints:

    `POST /vnc/start/{run_id}`:
    1. Auth required (get_current_user)
    2. Fetch Run — verify ownership via project (400 if run not found or not owned)
    3. Check run.status == "complete" — return 400 if not ("VNC viewer only available for completed runs")
    4. Check run.artifact_path is not None — return 400 if no artifacts yet
    5. Count active sessions for user: if existing "running" session for this run_id, return it (idempotent)
    6. Count ALL running VncSessions across all users; if >= settings.MAX_VNC_SESSIONS, return 429 ("VNC session limit reached — please try again later")
    7. Find an available port (base_port=6080, scan 6080-6099 for unused ports)
    8. Create VncSession record with status="starting"
    9. Dispatch `worker.tasks.vnc_session.start_vnc.delay(str(session.id))`
    10. Generate HMAC-signed VNC token using `create_vnc_token(str(user.id), str(run_id), port)` — uses VNC_TOKEN_SECRET, NOT JWT_SECRET_KEY (locked decision from STATE.md)
    11. Update session.token = token, session.expires_at = now + 2hr
    12. Return VncStartResponse with vnc_url = f"/vnc/{token}"

    `GET /vnc/validate?token={token}`:
    Called by Nginx auth_request. Do NOT require user Bearer token (this endpoint is called by Nginx, not the browser JS). Validate token using `decode_token(token, secret=settings.VNC_TOKEN_SECRET)`. Check type == "vnc" and not expired. Check VncSession with this token exists and status == "running". Return 200 if valid, 401 if invalid. Also return header `X-VNC-Port: {port}` on success (Nginx uses this for proxy_pass target).

    `DELETE /vnc/{session_id}`:
    Auth required. Verify user owns the session. Stop container via Docker SDK: `docker.from_env().containers.get(session.container_id).stop()`. Update session.status = "stopped". Return 204.

    **vnc-container/start_session.sh** — Load DEF into OpenROAD GUI:
    ```bash
    #!/bin/bash
    # Wait for Xvfb to be ready
    sleep 2
    export DISPLAY=:99

    # Pre-load student's DEF into OpenROAD GUI
    # VNC_DEF_PATH and VNC_LEF_PATH are set by the container environment
    openroad -gui -no_splash << 'EOF'
    if {[info exists env(VNC_LEF_PATH)] && [file exists $env(VNC_LEF_PATH)]} {
        read_lef $env(VNC_LEF_PATH)
    }
    if {[info exists env(VNC_DEF_PATH)] && [file exists $env(VNC_DEF_PATH)]} {
        read_def $env(VNC_DEF_PATH)
    }
    gui::show
    EOF
    ```
    Note: OpenROAD uses Tcl for its scripting interface. `gui::show` opens the Qt GUI window. The `read_lef`/`read_def` sequence pre-loads the student's layout. This matches the CLAUDE.md VNC Container Setup section.

    **infra/nginx/nginx.conf** — Update with VNC token routing:
    ```nginx
    # VNC token validation endpoint (internal)
    location = /vnc-validate {
        internal;
        proxy_pass http://backend:8000/api/v1/vnc/validate;
        proxy_pass_request_body off;
        proxy_set_header Content-Length "";
        proxy_set_header X-Original-URI $request_uri;
    }

    # VNC proxy: validate token then proxy to container port
    location ~ ^/vnc/([^/]+)/(.*)$ {
        auth_request /vnc-validate;
        auth_request_set $vnc_port $upstream_http_x_vnc_port;
        # Token in URL path (not query string) — prevents token logging in access.log
        proxy_pass http://localhost:$vnc_port/$2;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 7200s;  # 2hr VNC session timeout
    }
    ```
    Also ensure nginx:alpine image is used (includes ngx_http_auth_request_module by default).
